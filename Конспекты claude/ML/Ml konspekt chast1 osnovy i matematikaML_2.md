# Раздел 1. Что такое Machine Learning

## 1.1 Иерархия понятий

```
Artificial Intelligence (AI)
    └── Machine Learning (ML)
            └── Deep Learning (DL)

Data Science (DS) — смежная дисциплина, использующая ML как один из инструментов
```

**Artificial Intelligence (искусственный интеллект)** — максимально широкое понятие: любые системы, имитирующие "разумное" поведение — от простого набора правил (`if-else`) до самообучающихся нейросетей. Не всякий AI — это ML. Шахматная программа 1980-х годов, перебирающая ходы по жёстким правилам, — это AI, но не ML.

**Machine Learning (машинное обучение)** — подмножество AI, где система **не программируется явными правилами**, а **находит закономерности в данных** и строит модель, которая обобщает эти закономерности на новые, ранее не виденные данные.

> **Важно.** Ключевое отличие ML от классического программирования:
> 
> - Классическое программирование: `Правила + Данные → Результат`
> - Machine Learning: `Данные + Результат (примеры) → Правила (модель)`

**Deep Learning (глубокое обучение)** — подмножество ML, где модель — это нейронная сеть с несколькими ("глубокими") слоями. DL особенно эффективен там, где признаки сложно сформулировать вручную (изображения, звук, текст).

**Data Science (наука о данных)** — более широкая практическая дисциплина: сбор данных, их очистка, анализ, визуализация, построение моделей (в том числе ML) и интерпретация результатов для бизнеса. ML-инженер обычно фокусируется на моделях и их продакшене, Data Scientist — на анализе и извлечении инсайтов, но на практике роли сильно пересекаются.

## 1.2 Виды обучения

### Supervised Learning (обучение с учителем)

У нас есть данные, где **для каждого объекта уже известен правильный ответ** (label/target). Модель учится предсказывать этот ответ по признакам объекта.

Формально: дан набор пар $(x_i, y_i)$, где $x_i$ — признаки объекта, $y_i$ — известный правильный ответ. Задача — найти функцию $f$, такую что $f(x_i) \approx y_i$, и которая будет хорошо работать на новых объектах.

Делится на:

- **Regression** — целевая переменная непрерывная (цена квартиры, температура, выручка).
- **Classification** — целевая переменная категориальная (спам/не спам, класс изображения).

_Примеры_: кредитный скоринг, прогноз оттока клиентов, прогноз цены недвижимости.

### Unsupervised Learning (обучение без учителя)

Правильных ответов **нет**. Модель сама ищет структуру в данных: группирует похожие объекты, находит скрытые закономерности, сокращает размерность.

_Примеры_: сегментация клиентов (clustering), уменьшение размерности данных (PCA), поиск аномалий.

### Semi-Supervised Learning (частично контролируемое обучение)

Промежуточный случай: у нас есть **небольшое количество размеченных** данных и **большое количество неразмеченных**. Модель использует структуру неразмеченных данных, чтобы улучшить качество на размеченных.

_Пример_: у вас 100 000 фотографий, но вручную размечены только 500. Semi-supervised подходы позволяют использовать оставшиеся 99 500 без меток для улучшения модели.

### Reinforcement Learning (обучение с подкреплением)

Агент взаимодействует со средой, совершает действия и получает **награду или штраф**. Цель — научиться политике действий, максимизирующей суммарную награду во времени. Здесь нет статичного датасета — данные генерируются самим процессом взаимодействия.

_Примеры_: обучение робота ходьбе, игровые AI (AlphaGo), рекомендательные системы с обратной связью.

> **Запомни.** Главный вопрос для определения типа задачи: _"Есть ли у меня правильные ответы для обучения?"_ Если да и они непрерывны/категориальны → supervised. Если ответов нет → unsupervised. Если система учится через награду за действия → RL.

## 1.3 Базовый словарь терминов ML

Разберём термины на конкретном примере: у нас есть таблица данных о клиентах банка, и мы хотим предсказать, вернёт ли клиент кредит.

|Термин|Объяснение|Пример из нашей задачи|
|---|---|---|
|**Dataset (датасет)**|Весь набор данных, с которым работает модель|Таблица из 10 000 клиентов|
|**Observation / Sample (наблюдение)**|Одна строка данных, один объект|Один конкретный клиент|
|**Feature (признак)**|Одна характеристика объекта, столбец таблицы (кроме целевого)|Возраст, доход, стаж работы|
|**Target / Label (целевая переменная / метка)**|То, что модель должна предсказать|"Вернул кредит" / "Не вернул"|
|**Training set (обучающая выборка)**|Часть данных, на которой модель обучается|70% клиентов|
|**Validation set (валидационная выборка)**|Часть данных для настройки гиперпараметров и промежуточной проверки|15% клиентов|
|**Test set (тестовая выборка)**|Часть данных для финальной, "честной" оценки качества|15% клиентов, которые модель не видела ни разу|
|**Parameter (параметр)**|Значение, которое модель **выучивает сама** в процессе обучения|Коэффициенты $\beta$ в линейной регрессии|
|**Hyperparameter (гиперпараметр)**|Значение, которое **задаёт человек до обучения** и которое не выучивается из данных|Глубина дерева, learning rate|
|**Model (модель)**|Функция (или алгоритм), которая по признакам выдаёт предсказание|Обученное дерево решений|
|**Prediction (предсказание)**|Конкретный выходной результат модели для конкретного объекта|"Клиент №452 вернёт кредит с вероятностью 0.83"|
|**Inference (инференс)**|Процесс применения уже обученной модели к новым данным (в противоположность обучению)|Модель в продакшене оценивает нового заявителя|
|**Loss function (функция потерь)**|Функция, измеряющая, насколько предсказания модели далеки от истинных значений|MSE, Log-loss|
|**Optimization (оптимизация)**|Процесс подбора параметров модели, минимизирующий функцию потерь|Gradient Descent|

> **Типичная ошибка новичка.** Путать _parameter_ и _hyperparameter_. Простое правило: если значение появляется в процессе обучения "само" (веса, коэффициенты) — это parameter. Если вы задаёте его руками до старта обучения (количество деревьев, глубина, learning rate) — это hyperparameter.

# Раздел 2. Математика для Machine Learning

> Здесь разбирается **только та математика, которая реально используется** в ML-алгоритмах далее по курсу. Каждое понятие объясняется трижды: интуитивно → формально → на числовом примере.

## 2.1 Линейная алгебра

### Scalar (скаляр)

Обычное число. Например, $a = 5$. В ML скаляром может быть, например, learning rate $\eta = 0.01$ или одно значение признака.

### Vector (вектор)

Упорядоченный набор чисел. Геометрически — точка в пространстве или стрелка из начала координат.

$$\mathbf{x} = \begin{pmatrix} x_1 \ x_2 \ x_3 \end{pmatrix}$$

**Зачем в ML:** один объект данных (например, один клиент) обычно представляется как вектор признаков. Если у клиента есть возраст, доход и стаж, то клиент — это вектор $\mathbf{x} = (34, 55000, 7)$.

### Matrix (матрица)

Прямоугольная таблица чисел, состоящая из строк и столбцов.

$$X = \begin{pmatrix} x_{11} & x_{12} \ x_{21} & x_{22} \ x_{31} & x_{32} \end{pmatrix}$$

**Зачем в ML:** весь датасет — это матрица, где каждая строка — объект (observation), а каждый столбец — признак (feature). Матрица размером $3 \times 2$ выше — это 3 клиента с 2 признаками у каждого.

### Tensor (тензор)

Обобщение скаляра (0-мерный тензор), вектора (1-мерный) и матрицы (2-мерный) на произвольное число измерений. 3-мерный тензор можно представить как "стопку" матриц.

**Зачем в ML:** цветное изображение — это тензор размером `высота × ширина × 3 канала цвета (RGB)`. Батч из 32 изображений — уже 4-мерный тензор.

### Transpose (транспонирование)

Операция, при которой строки матрицы становятся столбцами и наоборот. Обозначается $X^T$.

$$X = \begin{pmatrix} 1 & 2 \ 3 & 4 \ 5 & 6 \end{pmatrix}, \quad X^T = \begin{pmatrix} 1 & 3 & 5 \ 2 & 4 & 6 \end{pmatrix}$$

**Зачем в ML:** транспонирование постоянно встречается в формулах (например, в нормальном уравнении линейной регрессии $\beta = (X^TX)^{-1}X^Ty$), потому что для матричного умножения нужно согласовывать размерности.

### Dot product (скалярное произведение)

Для двух векторов одинаковой длины — сумма произведений соответствующих элементов:

$$\mathbf{a} \cdot \mathbf{b} = \sum_{i=1}^{n} a_i b_i$$

**Числовой пример:** $\mathbf{a} = (1, 2, 3)$, $\mathbf{b} = (4, 5, 6)$: $$\mathbf{a} \cdot \mathbf{b} = 1\cdot4 + 2\cdot5 + 3\cdot6 = 4 + 10 + 18 = 32$$

**Зачем в ML:** это _сердце_ линейных моделей. Предсказание линейной регрессии — это скалярное произведение вектора признаков на вектор весов: $\hat{y} = \mathbf{w} \cdot \mathbf{x} + b$.

### Matrix multiplication (умножение матриц)

Обобщение скалярного произведения на матрицы. Элемент результата в позиции $(i, j)$ — это скалярное произведение $i$-й строки первой матрицы и $j$-го столбца второй.

$$\left(\begin{matrix}1 & 2\3 & 4\end{matrix}\right) \times \left(\begin{matrix}5 & 6\7 & 8\end{matrix}\right) = \left(\begin{matrix}1\cdot5+2\cdot7 & 1\cdot6+2\cdot8\3\cdot5+4\cdot7 & 3\cdot6+4\cdot8\end{matrix}\right) = \left(\begin{matrix}19 & 22\43 & 50\end{matrix}\right)$$

**Зачем в ML:** предсказания сразу для всего датасета вычисляются одной матричной операцией $\hat{\mathbf{y}} = X\mathbf{w}$ — это на порядки быстрее, чем цикл по объектам, и именно так это реализовано в NumPy/PyTorch/TensorFlow (векторизация вычислений).

### Norm (норма)

"Длина" вектора — число, показывающее его величину. Самая частая — **L2-норма (евклидова)**:

$$|\mathbf{x}|_2 = \sqrt{\sum_{i=1}^n x_i^2}$$

Также используется **L1-норма**:

$$|\mathbf{x}|_1 = \sum_{i=1}^n |x_i|$$

**Числовой пример:** для $\mathbf{x} = (3, 4)$: $|\mathbf{x}|_2 = \sqrt{9+16} = \sqrt{25} = 5$.

**Зачем в ML:** нормы лежат в основе регуляризации (Ridge использует L2, Lasso использует L1 — подробно в Части 2) и метрик расстояния.

### Distance (расстояние)

Мера "непохожести" двух объектов. **Евклидово расстояние** между векторами $\mathbf{a}$ и $\mathbf{b}$ — это норма их разности:

$$d(\mathbf{a}, \mathbf{b}) = |\mathbf{a} - \mathbf{b}|_2 = \sqrt{\sum_{i=1}^n (a_i - b_i)^2}$$

**Зачем в ML:** это основа алгоритма KNN, K-Means и многих других методов, где важно понятие "похожести" объектов.

### Linear transformation (линейное преобразование)

Функция, которая переводит вектор в другой вектор через умножение на матрицу: $\mathbf{y} = A\mathbf{x}$. Она сохраняет линейные комбинации: прямые линии остаются прямыми, начало координат остаётся на месте.

**Зачем в ML:** каждый слой нейронной сети (до применения нелинейности) — это линейное преобразование входа.

### Eigenvalues и Eigenvectors (собственные значения и собственные векторы)

**Интуиция:** для большинства векторов умножение на матрицу $A$ меняет и длину, и направление вектора. Но для некоторых особых векторов умножение на $A$ меняет **только длину**, направление сохраняется (или разворачивается на 180°). Такой вектор называется собственным (eigenvector), а во сколько раз меняется его длина — собственным значением (eigenvalue).

**Формальное определение:**

$$A\mathbf{v} = \lambda \mathbf{v}$$

где $A$ — матрица, $\mathbf{v}$ — собственный вектор (eigenvector), $\lambda$ — собственное значение (eigenvalue), число.

**Зачем в ML:** это математическое ядро PCA (Part 5). Собственные векторы матрицы ковариации данных показывают направления наибольшей вариации данных, а собственные значения — сколько "информации" (дисперсии) содержится в каждом из этих направлений.

> **Важно.** Не нужно уметь вручную находить собственные значения для больших матриц — это делает `numpy.linalg.eig()`. Важно понимать **смысл**: eigenvector — это "устойчивое направление" преобразования, eigenvalue — "во сколько раз оно растягивается".

## 2.2 Математический анализ (Calculus)

### Функция

Правило, которое каждому входному значению ставит в соответствие ровно одно выходное. В ML функция часто зависит от параметров модели: $J(\theta)$ — функция потерь, зависящая от параметров $\theta$.

### Производная (derivative)

**Интуиция:** производная показывает, **насколько быстро меняется функция** при малом изменении её аргумента — "наклон" графика функции в точке.

**Формальное определение:**

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

**Числовой пример:** для $f(x) = x^2$, производная $f'(x) = 2x$. В точке $x=3$: наклон касательной равен $6$ — то есть при малом увеличении $x$ функция растёт примерно в 6 раз быстрее, чем сам $x$.

**Зачем в ML:** производная показывает направление и скорость, с которой нужно менять параметр модели, чтобы уменьшить (или увеличить) функцию потерь.

### Частная производная (partial derivative)

Когда функция зависит от **нескольких** переменных, частная производная — это производная по одной из них, при этом все остальные считаются **зафиксированными (константами)**.

Пример: если $J(\theta_1, \theta_2) = \theta_1^2 + 3\theta_1\theta_2$, то:

$$\frac{\partial J}{\partial \theta_1} = 2\theta_1 + 3\theta_2, \qquad \frac{\partial J}{\partial \theta_2} = 3\theta_1$$

**Зачем в ML:** модель почти всегда имеет много параметров одновременно (сотни весов в линейной регрессии, миллионы — в нейросети), и нужно понимать, как функция потерь меняется по каждому параметру в отдельности.

### Градиент (gradient)

**Интуиция:** градиент — это вектор, собранный из всех частных производных функции. Он указывает направление **наискорейшего возрастания** функции в данной точке.

**Формальное определение:** для функции $J(\theta_1, ..., \theta_n)$:

$$\nabla J(\theta) = \begin{pmatrix} \dfrac{\partial J}{\partial \theta_1} \ \vdots \ \dfrac{\partial J}{\partial \theta_n} \end{pmatrix}$$

**Направление градиента:** так как $\nabla J$ указывает направление **наискорейшего роста** функции, то направление $-\nabla J$ указывает направление **наискорейшего убывания**. Именно поэтому в оптимизации мы двигаемся _против_ градиента.

**Зачем в ML:** градиент — это компас, который на каждом шаге обучения показывает, в какую сторону и насколько сильно изменить каждый параметр модели, чтобы уменьшить ошибку.

### Chain rule (правило цепочки / производная сложной функции)

Если функция $y$ зависит от $u$, а $u$ зависит от $x$ (то есть $y = f(u(x))$ — сложная функция), то:

$$\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$$

**Числовой пример:** пусть $y = u^2$, а $u = 3x + 1$. Тогда $\dfrac{dy}{du} = 2u$, $\dfrac{du}{dx} = 3$, значит: $$\frac{dy}{dx} = 2u \cdot 3 = 6u = 6(3x+1) = 18x + 6$$

**Зачем в ML:** это математический фундамент **backpropagation** — алгоритма обучения нейросетей. Нейросеть — это композиция множества функций (слоёв), и chain rule позволяет посчитать, как ошибка на выходе влияет на веса самого первого слоя, "прокатив" производную через всю цепочку.

### Минимум функции: локальный и глобальный

- **Локальный минимум** — точка, в которой значение функции меньше, чем во всех _соседних_ точках, но не обязательно меньше, чем во всех точках функции вообще.
- **Глобальный минимум** — точка с наименьшим значением функции **на всей области определения**.

> **Важно.** Многие функции потерь в ML (например, MSE в линейной регрессии) — **выпуклые (convex)**, у них локальный минимум всегда совпадает с глобальным. Но функции потерь нейросетей — **невыпуклые**, у них может быть множество локальных минимумов, и Gradient Descent не гарантирует нахождение глобального.

### Gradient Descent (градиентный спуск) — подробный разбор

**Интуиция:** представьте, что вы стоите на холмистой поверхности с завязанными глазами и хотите спуститься в самую низкую точку. Логичная стратегия — на каждом шаге ощупывать землю под ногами (определять наклон) и делать шаг в сторону, где поверхность идёт вниз круче всего. Повторять, пока не окажетесь в низине.

**Формула обновления параметров:**

$$\theta := \theta - \eta \nabla J(\theta)$$

Разберём **каждый символ**:

|Символ|Значение|
|---|---|
|$\theta$|Вектор параметров модели (веса), которые мы хотим найти|
|$:=$|"Присвоить новое значение" (обновление, а не математическое равенство)|
|$\eta$ (эта)|**Learning rate** — гиперпараметр, задающий размер шага|
|$\nabla J(\theta)$|Градиент функции потерь $J$ по параметрам $\theta$ — направление наискорейшего роста ошибки|
|$-\nabla J(\theta)$|Направление наискорейшего **убывания** ошибки — туда мы и двигаемся|

**Почему вычитаем, а не прибавляем:** градиент указывает направление роста функции. Нам нужно её _уменьшить_, поэтому двигаемся в противоположную сторону — отсюда знак минус.

**Роль learning rate $\eta$:**

- Если $\eta$ слишком маленький — обучение идёт очень медленно, потребуется много итераций.
- Если $\eta$ слишком большой — можно "перепрыгнуть" через минимум и разойтись, вместо сходимости получим колебания или расхождение.

> **Типичная ошибка новичка.** Ставить слишком большой learning rate "чтобы обучилось побыстрее" — и получать `loss = NaN` уже на второй-третьей итерации из-за расхождения.

**Пошаговый числовой пример.**

Пусть мы минимизируем простейшую функцию одной переменной $J(\theta) = \theta^2$ (в реальности $J$ — это функция потерь модели, но для понимания механики возьмём простую функцию). Её производная: $J'(\theta) = 2\theta$.

Возьмём начальную точку $\theta_0 = 5$ и learning rate $\eta = 0.3$.

**Итерация 1:** $$\theta_1 = \theta_0 - \eta \cdot J'(\theta_0) = 5 - 0.3 \cdot (2 \cdot 5) = 5 - 0.3\cdot10 = 5 - 3 = 2$$

**Итерация 2:** $$\theta_2 = 2 - 0.3 \cdot (2 \cdot 2) = 2 - 0.3\cdot4 = 2 - 1.2 = 0.8$$

**Итерация 3:** $$\theta_3 = 0.8 - 0.3\cdot(2\cdot0.8) = 0.8 - 0.48 = 0.32$$

**Итерация 4:** $$\theta_4 = 0.32 - 0.3\cdot(2\cdot0.32) = 0.32 - 0.192 = 0.128$$

Видно, что $\theta$ шаг за шагом приближается к истинному минимуму функции $J(\theta)=\theta^2$, который находится в точке $\theta=0$ (наименьшее значение $\theta^2$ достигается при $\theta = 0$). С каждой итерацией шаг становится меньше, потому что градиент ($2\theta$) сам уменьшается по мере приближения к минимуму.

```python
import numpy as np

theta = 5.0
eta = 0.3
history = [theta]

for i in range(10):
    grad = 2 * theta          # производная J(theta) = theta^2
    theta = theta - eta * grad  # шаг градиентного спуска
    history.append(theta)

print(history)
# [5.0, 2.0, 0.8, 0.32, 0.128, 0.0512, ...] -> сходится к 0
```

> **Запомни.** Gradient Descent — это не конкретный алгоритм ML, а **универсальный метод оптимизации**, лежащий в основе обучения линейной регрессии, логистической регрессии, нейросетей и многого другого. Разные ML-алгоритмы отличаются тем, **что** именно является функцией $J(\theta)$, но механика обновления параметров одна и та же.

**Разновидности Gradient Descent** (кратко, подробнее — в контексте конкретных алгоритмов):

|Вид|Как считается градиент|Плюсы|Минусы|
|---|---|---|---|
|**Batch GD**|По всему датасету сразу на каждой итерации|Точный, стабильный градиент|Медленно на больших данных|
|**Stochastic GD (SGD)**|По одному случайному объекту на каждой итерации|Быстрые шаги, может выбираться из локальных минимумов|Шумный, "дёрганый" путь к минимуму|
|**Mini-batch GD**|По небольшой случайной подвыборке (например, 32–256 объектов)|Баланс скорости и стабильности|Нужно подбирать размер батча|

## 2.3 Теория вероятностей

### Probability (вероятность)

Число от 0 до 1, показывающее, насколько вероятно наступление события. $P(A) = 0$ — событие невозможно, $P(A) = 1$ — событие произойдёт гарантированно.

### Conditional probability (условная вероятность)

Вероятность события $A$ **при условии**, что уже произошло событие $B$:

$$P(A|B) = \frac{P(A \cap B)}{P(B)}$$

**Пример:** вероятность того, что клиент купит товар ($A$), при условии, что он уже добавил его в корзину ($B$), обычно намного выше, чем безусловная вероятность покупки.

### Bayes theorem (теорема Байеса)

Позволяет "развернуть" условную вероятность — найти $P(A|B)$, зная $P(B|A)$:

$$P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$$

Разберём обозначения:

- $P(A)$ — **prior** (априорная вероятность) — вероятность $A$ до того, как мы узнали про $B$.
- $P(A|B)$ — **posterior** (апостериорная вероятность) — вероятность $A$ после учёта информации о $B$.
- $P(B|A)$ — **likelihood** (правдоподобие) — насколько вероятно $B$, если $A$ истинно.
- $P(B)$ — вероятность самого $B$ (нормировочный множитель).

**Зачем в ML:** это математическая основа алгоритма Naive Bayes (Часть 3), а также общий принцип байесовского мышления, используемый, например, в Bayesian Optimization для подбора гиперпараметров.

### Random variable (случайная величина)

Переменная, значение которой определяется случайным экспериментом. **Дискретная** случайная величина принимает счётное число значений (число дефолтов по кредитам), **непрерывная** — любое значение в интервале (доход клиента).

### Expectation (математическое ожидание)

"Среднее" значение случайной величины с учётом вероятностей каждого исхода:

$$E[X] = \sum_i x_i P(x_i) \quad \text{(дискретный случай)}$$

**Зачем в ML:** функция потерь на всём датасете — это, по сути, оценка математического ожидания ошибки модели.

### Variance (дисперсия)

Мера разброса случайной величины вокруг её среднего:

$$\text{Var}(X) = E[(X - E[X])^2]$$

**Зачем в ML:** дисперсия — ключевое понятие в bias-variance tradeoff (Часть 6): она показывает, насколько сильно предсказания модели меняются при обучении на разных выборках данных.

### Covariance (ковариация)

Показывает, как **совместно** меняются две случайные величины:

$$\text{Cov}(X,Y) = E[(X-E[X])(Y-E[Y])]$$

Положительная ковариация — переменные растут вместе, отрицательная — одна растёт, когда другая убывает, около нуля — линейной связи нет.

**Зачем в ML:** ковариационная матрица признаков — основа PCA (Часть 5).

### Распределения (distributions)

**Normal distribution (нормальное распределение / распределение Гаусса)** — колоколообразное симметричное распределение, задаётся средним $\mu$ и дисперсией $\sigma^2$:

$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

Очень часто встречается в природе и данных (рост людей, ошибки измерений) — на нём базируется, например, Gaussian Naive Bayes.

**Bernoulli distribution (распределение Бернулли)** — распределение случайной величины с ровно двумя исходами (0 или 1) с вероятностью успеха $p$. Модель бинарной классификации (например, логистическая регрессия) предсказывает именно параметр $p$ распределения Бернулли для каждого объекта.

**Binomial distribution (биномиальное распределение)** — распределение числа "успехов" в серии из $n$ независимых испытаний Бернулли с вероятностью успеха $p$ в каждом.

## 2.4 Статистика

### Меры центральной тенденции

- **Mean (среднее арифметическое):** $\bar{x} = \frac{1}{n}\sum_{i=1}^n x_i$ — чувствительно к выбросам.
- **Median (медиана):** значение, разделяющее упорядоченный набор данных пополам — устойчиво к выбросам.
- **Mode (мода):** наиболее часто встречающееся значение — единственная мера центра, применимая к категориальным данным.

> **Типичная ошибка новичка.** Использовать среднее для заполнения пропусков в признаке с сильными выбросами (например, доход). Из-за пары клиентов-миллионеров среднее может сильно исказиться — в таких случаях лучше использовать медиану.

### Меры разброса

- **Variance (дисперсия):** $\sigma^2 = \frac{1}{n}\sum(x_i - \bar{x})^2$
- **Standard deviation (стандартное отклонение):** $\sigma = \sqrt{\sigma^2}$ — измеряется в тех же единицах, что и сам признак, поэтому интерпретируется проще, чем дисперсия.
- **Quantiles (квантили):** значения, делящие упорядоченные данные на равные части (медиана — это 0.5-квантиль; квартили делят данные на 4 части).

### Correlation (корреляция)

Нормированная ковариация, значение от $-1$ до $1$, показывающее силу и направление **линейной** связи между двумя переменными:

$$r = \frac{\text{Cov}(X,Y)}{\sigma_X \sigma_Y}$$

> **Важно.** Корреляция измеряет только **линейную** связь. Две переменные могут быть сильно связаны нелинейно (например, $y = x^2$) и при этом иметь корреляцию, близкую к нулю. "Корреляция не означает причинность" — классическое правило: то, что два признака коррелируют, не значит, что один вызывает другой.

### Confidence interval (доверительный интервал)

Диапазон значений, в котором с заданной вероятностью (например, 95%) находится истинное значение оцениваемого параметра (например, среднего по генеральной совокупности), рассчитанный на основе выборки.

### Hypothesis testing (проверка статистических гипотез) и p-value

**Идея:** мы формулируем нулевую гипотезу $H_0$ (например, "новая версия сайта не отличается по конверсии от старой") и проверяем, насколько наблюдаемые данные ей противоречат.

**p-value** — вероятность получить наблюдаемый (или более экстремальный) результат, **если нулевая гипотеза верна**. Маленький p-value (обычно < 0.05) — повод усомниться в $H_0$ и говорить о статистически значимом эффекте.

> **Типичная ошибка новичка.** Интерпретировать p-value как "вероятность того, что гипотеза верна". Это неверно — p-value ничего не говорит напрямую о вероятности истинности гипотезы, только о совместимости данных с $H_0$.

**Зачем в ML:** статистика используется на этапе EDA (разведочного анализа данных), при A/B-тестировании моделей в продакшене, при оценке значимости различий в метриках между моделями.
