# Linear Regression (Линейная регрессия)

## 1. Что решает алгоритм

Linear Regression решает задачу **регрессии**: предсказание **непрерывной** числовой целевой переменной на основе одного или нескольких признаков.

_Примеры задач:_ предсказание цены квартиры по площади и району, предсказание выручки по маркетинговому бюджету, предсказание времени доставки по расстоянию.

Формально: дан датасет из $n$ объектов с $p$ признаками. Нужно найти функцию $\hat{y} = f(x)$, приближающую истинную зависимость между признаками $X$ и целевой переменной $y$, причём в линейной регрессии мы **заранее предполагаем**, что эта зависимость линейна.

## 2. Интуиция

Представьте график: по оси X — площадь квартиры, по оси Y — её цена. Точки на графике — реальные квартиры из вашего датасета. Они образуют облако, в котором в целом видна тенденция: чем больше площадь, тем выше цена.

**Linear Regression пытается провести через это облако точек одну прямую линию (а в случае нескольких признаков — гиперплоскость) так, чтобы она была максимально близко ко всем точкам одновременно.**

"Максимально близко" — это не интуитивное понятие, а строго определённый математический критерий (функция потерь), который мы разберём ниже. Модель не пытается пройти _через_ каждую точку (это привело бы к переобучению), а ищет линию, которая в среднем минимизирует ошибку по всем точкам.

## 3. Математическая идея

### Простая линейная регрессия (один признак)

$$y = \beta_0 + \beta_1 x$$

- $x$ — признак (например, площадь квартиры).
- $y$ — целевая переменная (цена).
- $\beta_0$ (**intercept**, свободный член) — значение $y$ при $x=0$; геометрически — точка пересечения прямой с осью Y.
- $\beta_1$ (**coefficient**, коэффициент наклона) — насколько изменится $y$ при увеличении $x$ на единицу. Это "крутизна" линии.

### Множественная линейная регрессия (несколько признаков)

Когда признаков много ($x_1, x_2, ..., x_p$ — например, площадь, этаж, расстояние до метро), уравнение обобщается:

$$\hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_p x_p$$

В матричной форме, для всего датасета сразу:

$$\hat{\mathbf{y}} = X\boldsymbol{\beta}$$

Разберём эту компактную запись:

- $X$ — матрица признаков размером $n \times (p+1)$: $n$ строк-объектов, $p$ столбцов-признаков плюс один дополнительный столбец из единиц (для intercept $\beta_0$).
- $\boldsymbol{\beta}$ — вектор из $(p+1)$ параметров: $(\beta_0, \beta_1, ..., \beta_p)$.
- $\hat{\mathbf{y}}$ — вектор предсказаний для всех $n$ объектов.

> **Важно.** Умножение матрицы $X$ на вектор $\boldsymbol{\beta}$ — это ровно то самое matrix multiplication из Части 1: для каждого объекта (строки) мы считаем скалярное произведение его признаков на вектор весов. Именно поэтому предсказания для всего датасета вычисляются одной операцией, без циклов.

**Что модель "выучивает":** обучение линейной регрессии = поиск такого вектора $\boldsymbol{\beta}$, при котором предсказания $\hat{\mathbf{y}}$ максимально близки к истинным значениям $\mathbf{y}$.

## 4. Как алгоритм работает (пошагово)

1. Инициализировать параметры $\boldsymbol{\beta}$ (например, нулями или случайными малыми значениями).
2. Посчитать предсказания $\hat{y}_i = \beta_0 + \beta_1 x_{i1} + ... + \beta_p x_{ip}$ для всех объектов.
3. Посчитать функцию потерь (MSE) — насколько предсказания отличаются от истинных значений.
4. Обновить параметры $\boldsymbol{\beta}$ в направлении уменьшения ошибки (через Gradient Descent или аналитически через Normal Equation — см. ниже).
5. Повторять шаги 2–4, пока ошибка не перестанет существенно уменьшаться (для Gradient Descent) — либо получить решение сразу за одну операцию (для Normal Equation).
6. Итоговые $\boldsymbol{\beta}$ — обученная модель, готовая делать предсказания на новых данных.

## Loss Function: вывод MSE

**Mean Squared Error (среднеквадратичная ошибка):**

$$MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$

Разберём по частям:

- $y_i$ — истинное значение целевой переменной для объекта $i$.
- $\hat{y}_i$ — предсказание модели для объекта $i$.
- $(y_i - \hat{y}_i)$ — **residual (остаток)**, ошибка на одном конкретном объекте. Может быть положительной (модель занизила) или отрицательной (модель завысила).
- $(y_i - \hat{y}_i)^2$ — квадрат ошибки: всегда неотрицателен.
- $\sum_{i=1}^n (...)$ — суммируем квадраты ошибок по всем $n$ объектам.
- $\frac{1}{n}$ — делим на число объектов, чтобы получить **среднюю** ошибку, не зависящую от размера датасета.

**Почему используется именно квадрат ошибки, а не, например, модуль ошибки ($|y_i - \hat{y}_i|$)?**

1. **Дифференцируемость.** $x^2$ — гладкая функция, у неё везде существует производная, что критически важно для Gradient Descent. У $|x|$ производная не определена в нуле — это создаёт технические сложности при оптимизации.
2. **Штраф за большие ошибки растёт быстрее.** Квадрат "наказывает" большие отклонения значительно сильнее маленьких: ошибка в 10 единиц даёт вклад 100, ошибка в 2 единицы — вклад всего 4. Это заставляет модель особенно стараться не допускать грубых промахов.
3. **Выпуклость.** MSE как функция от параметров $\boldsymbol{\beta}$ — выпуклая функция (вспомните Часть 1, раздел про локальный/глобальный минимум), а значит, у неё есть единственный минимум, и Gradient Descent гарантированно его найдёт (при разумном learning rate).

> **Типичная ошибка новичка.** Из-за квадратичного штрафа MSE **очень чувствительна к выбросам** — один аномальный объект с большой ошибкой может сильно "перетянуть" модель на себя. Если в данных много выбросов, часто более уместна MAE (Mean Absolute Error, разбирается в Части 6) или предварительная обработка выбросов.

## Optimization: как находятся параметры

### Способ 1 — Gradient Descent

Мы применяем формулу из Части 1: $\theta := \theta - \eta \nabla J(\theta)$, где $J(\theta) = MSE$.

Нужно найти градиент MSE по каждому параметру $\beta_j$. Для параметра $\beta_j$ (при $j \geq 1$, то есть не для intercept):

$$\frac{\partial MSE}{\partial \beta_j} = -\frac{2}{n}\sum_{i=1}^{n} x_{ij}(y_i - \hat{y}_i)$$

Интуитивно: градиент по $\beta_j$ показывает, насколько сильно и в какую сторону нужно изменить этот конкретный коэффициент, чтобы уменьшить суммарную ошибку — учитывая **и величину остатков, и значение самого признака** $x_{ij}$ (если признак большой, его коэффициент сильнее влияет на предсказание, значит, и градиент по нему больше).

Далее просто применяем обновление: $\beta_j := \beta_j - \eta \cdot \frac{\partial MSE}{\partial \beta_j}$ — на каждой итерации для всех коэффициентов одновременно (в матричной форме это можно сделать одной операцией).

### Способ 2 — Normal Equation (нормальное уравнение)

Для линейной регрессии, в отличие от большинства других ML-моделей, можно найти оптимальные параметры **аналитически, за одно вычисление**, не делая итераций:

$$\boldsymbol{\beta} = (X^TX)^{-1}X^T\mathbf{y}$$

Это получается, если приравнять градиент MSE к нулю и решить уравнение относительно $\boldsymbol{\beta}$ — классическая математическая задача поиска минимума через производную.

**Разбор:** $X^TX$ — квадратная матрица, $(X^TX)^{-1}$ — обратная к ней матрица (аналог деления, но для матриц), а затем всё умножается на $X^T\mathbf{y}$.

### Почему существуют два разных способа?

||Gradient Descent|Normal Equation|
|---|---|---|
|Тип решения|Итеративное приближение|Точное аналитическое решение за один шаг|
|Скорость при малом числе признаков|Медленнее (нужны итерации)|Быстрее|
|Скорость при очень большом числе признаков ($p$ > ~10 000)|Хорошо масштабируется|Медленно: вычисление $(X^TX)^{-1}$ имеет сложность $O(p^3)$|
|Нужен ли learning rate|Да, нужно подбирать|Не требуется|
|Работает ли, если $X^TX$ необратима|Да (не зависит от обратимости)|Нет (нужны трюки вроде регуляризации)|
|Обобщается ли на другие модели (логистическая регрессия, нейросети)|Да, универсальный метод|Нет, работает только для линейной регрессии (и похожих задач)|

> **Запомни.** На практике в scikit-learn `LinearRegression()` по умолчанию использует аналог Normal Equation (через SVD-разложение, что более численно устойчиво), а Gradient Descent используется в `SGDRegressor` — и обязательно в нейросетях, где аналитического решения не существует в принципе.

## Regularization: Ridge, Lasso, Elastic Net

**Проблема, которую решает регуляризация:** при большом числе признаков (особенно коррелированных между собой) обычная линейная регрессия склонна к переобучению — коэффициенты $\beta$ могут "разрастись" до экстремально больших значений, подстраиваясь под шум в обучающих данных.

**Общая идея:** добавить к функции потерь **штраф за величину коэффициентов**. Модель теперь должна не только минимизировать ошибку предсказания, но и "платить" за большие по модулю веса — это заставляет её выбирать более простые, устойчивые решения.

### Ridge Regression (L2-регуляризация)

$$J(\boldsymbol{\beta}) = \underbrace{\frac{1}{n}\sum_{i=1}^n (y_i - \hat{y}_i)^2}_{MSE} + \underbrace{\alpha \sum_{j=1}^{p} \beta_j^2}_{\text{L2-штраф}}$$

- $\alpha$ (иногда обозначают $\lambda$) — гиперпараметр силы регуляризации.
- $\sum \beta_j^2$ — сумма квадратов коэффициентов (без intercept $\beta_0$, его обычно не регуляризуют).

**Эффект на коэффициенты:** Ridge **уменьшает** величину всех коэффициентов пропорционально (сжимает их к нулю), но **никогда не обнуляет их полностью**. Это плавное "сжатие" (shrinkage).

### Lasso Regression (L1-регуляризация)

$$J(\boldsymbol{\beta}) = \frac{1}{n}\sum_{i=1}^n (y_i - \hat{y}_i)^2 + \alpha \sum_{j=1}^{p} |\beta_j|$$

**Эффект на коэффициенты:** из-за геометрии L1-нормы (в отличие от гладкой L2), Lasso способен **обнулять** коэффициенты незначимых признаков полностью. Это делает Lasso удобным инструментом **автоматического отбора признаков (feature selection)** — после обучения можно просто выбросить признаки с нулевым коэффициентом.

> **Важно.** Геометрическая интуиция: область допустимых значений при L1-ограничении — это "ромб" (в 2D) с острыми углами на осях координат, и оптимум функции потерь часто оказывается именно в углу — то есть с одной из координат (коэффициентов), равной нулю. При L2 область — окружность без углов, поэтому коэффициенты плавно уменьшаются, но точного нуля не достигают.

### Elastic Net

Комбинация L1 и L2:

$$J(\boldsymbol{\beta}) = \frac{1}{n}\sum_{i=1}^n(y_i-\hat{y}_i)^2 + \alpha\rho\sum_{j=1}^p|\beta_j| + \alpha(1-\rho)\sum_{j=1}^p\beta_j^2$$

- $\rho$ (l1_ratio в sklearn) — доля L1 в общей регуляризации (от 0 до 1).

Elastic Net берёт лучшее из обоих миров: может обнулять незначимые коэффициенты (как Lasso), но при этом устойчивее работает с сильно коррелированными признаками (как Ridge — Lasso в таких случаях может случайно выбрать один признак из группы коррелированных и обнулить остальные, что не всегда желательно).

||Ridge (L2)|Lasso (L1)|Elastic Net|
|---|---|---|---|
|Обнуляет коэффициенты|Нет|Да|Да (частично)|
|Хорош при мультиколлинеарности|Да|Хуже|Да|
|Делает feature selection|Нет|Да|Да|
|Когда использовать|Много признаков, все потенциально полезны|Много признаков, подозрение, что многие бесполезны|Признаков много и они коррелируют между собой|

> **Важно.** Перед применением любой регуляризации признаки **обязательно** нужно масштабировать (стандартизировать), иначе штраф будет несправедливо сильнее давить на признаки с большим численным диапазоном значений просто из-за единиц измерения, а не из-за реальной значимости. Подробнее о scaling — в Части 6.

## 5. Минимальный математический пример

Возьмём крошечный датасет: площадь квартиры (в десятках м²) и её цена (в млн ₽).

|$x$ (площадь, дес. м²)|$y$ (цена, млн ₽)|
|---|---|
|3|6|
|4|8|
|5|9|
|6|11|

Посчитаем коэффициенты простой линейной регрессии по формулам метода наименьших квадратов:

$$\beta_1 = \frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sum(x_i - \bar{x})^2}, \qquad \beta_0 = \bar{y} - \beta_1 \bar{x}$$

$\bar{x} = \frac{3+4+5+6}{4} = 4.5$, $\bar{y} = \frac{6+8+9+11}{4} = 8.5$

|$x_i - \bar{x}$|$y_i - \bar{y}$|произведение|$(x_i-\bar{x})^2$|
|---|---|---|---|
|-1.5|-2.5|3.75|2.25|
|-0.5|-0.5|0.25|0.25|
|0.5|0.5|0.25|0.25|
|1.5|2.5|3.75|2.25|
|**Сумма**||**8.0**|**5.0**|

$$\beta_1 = \frac{8.0}{5.0} = 1.6, \qquad \beta_0 = 8.5 - 1.6 \cdot 4.5 = 8.5 - 7.2 = 1.3$$

**Итоговая модель:** $\hat{y} = 1.3 + 1.6x$

Проверим на первом объекте ($x=3$): $\hat{y} = 1.3 + 1.6\cdot3 = 1.3+4.8=6.1$ (истинное значение — 6, ошибка совсем маленькая).

Посчитаем MSE по всем 4 объектам: предсказания — $6.1,\ 7.7,\ 9.3,\ 10.9$; истинные — $6,\ 8,\ 9,\ 11$; остатки — $0.1,\ -0.3,\ 0.3,\ -0.1$; квадраты остатков — $0.01,\ 0.09,\ 0.09,\ 0.01$.

$$MSE = \frac{0.01+0.09+0.09+0.01}{4} = \frac{0.2}{4} = 0.05$$

## 6. Python

### Реализация "с нуля" на NumPy (через Gradient Descent)

```python
import numpy as np

# Тот же датасет, что и в математическом примере
X = np.array([3, 4, 5, 6], dtype=float).reshape(-1, 1)
y = np.array([6, 8, 9, 11], dtype=float)

n = len(y)
# Добавляем столбец единиц для intercept (beta_0)
X_b = np.hstack([np.ones((n, 1)), X])  # столбец 1 + столбец x

beta = np.zeros(2)      # инициализация [beta_0, beta_1]
eta = 0.05               # learning rate
n_iterations = 2000

for iteration in range(n_iterations):
    y_pred = X_b @ beta                  # предсказания: X_b * beta (matrix mult.)
    residuals = y_pred - y               # ошибки (обратный знак для удобства градиента)
    gradients = (2/n) * X_b.T @ residuals  # градиент MSE по всем beta сразу
    beta = beta - eta * gradients        # шаг градиентного спуска

print("beta_0 (intercept):", beta[0])
print("beta_1 (coefficient):", beta[1])
# Ожидаем значения, близкие к 1.3 и 1.6, посчитанным вручную выше
```

**Пояснение ключевых строк:**

- `X_b = np.hstack([...])` — добавляем столбец единиц, чтобы intercept $\beta_0$ вычислялся той же матричной операцией, что и остальные коэффициенты (умножение на 1 не меняет значение).
- `y_pred = X_b @ beta` — это ровно формула $\hat{\mathbf{y}} = X\boldsymbol{\beta}$ из раздела 3, векторизованно для всех объектов сразу.
- `gradients = (2/n) * X_b.T @ residuals` — векторизованная версия формулы частной производной MSE, посчитанная сразу для всех коэффициентов через умножение $X^T$ на вектор остатков.

### Production-style реализация через scikit-learn

```python
from sklearn.linear_model import LinearRegression, Ridge, Lasso, ElasticNet
import numpy as np

X = np.array([3, 4, 5, 6], dtype=float).reshape(-1, 1)
y = np.array([6, 8, 9, 11], dtype=float)

model = LinearRegression()
model.fit(X, y)              # обучение: sklearn использует аналог Normal Equation

print("intercept:", model.intercept_)   # ~1.3
print("coefficient:", model.coef_)      # ~1.6

new_flat = np.array([[7]])   # новая квартира, площадь 70 м²
print("prediction:", model.predict(new_flat))

# С регуляризацией — на реальных данных ПЕРЕД этим нужно масштабировать признаки
ridge = Ridge(alpha=1.0).fit(X, y)
lasso = Lasso(alpha=0.1).fit(X, y)
elastic = ElasticNet(alpha=0.1, l1_ratio=0.5).fit(X, y)
```

## 7. Важные гиперпараметры

|Параметр|Значение|Эффект|
|---|---|---|
|`alpha` (Ridge/Lasso/ElasticNet)|Сила регуляризации|Больше `alpha` → сильнее сжатие коэффициентов → меньше overfitting, но риск underfitting при слишком большом значении|
|`l1_ratio` (ElasticNet)|Баланс L1/L2 (0 до 1)|Ближе к 1 → ведёт себя как Lasso; ближе к 0 → как Ridge|
|`learning_rate` / `eta0` (при использовании SGDRegressor)|Размер шага Gradient Descent|Слишком большой — расхождение; слишком маленький — медленное обучение|
|`max_iter`|Максимум итераций (для итеративных решателей)|Мало итераций → модель может не успеть сойтись|
|`fit_intercept`|Учитывать ли $\beta_0$|`False` заставляет линию/гиперплоскость проходить через начало координат — почти всегда должно быть `True`|

## 8. Переобучение (Overfitting) в Linear Regression

Простая линейная регрессия с малым числом признаков **редко переобучается сама по себе** — она довольно "жёсткая" модель (высокий bias, низкий variance). Переобучение чаще возникает, если:

- признаков очень много относительно числа наблюдений ($p$ сопоставимо с $n$ или больше);
- используются полиномиальные/производные признаки высокой степени (polynomial features);
- признаки сильно коррелируют друг с другом (мультиколлинеарность) — коэффициенты становятся неустойчивыми, сильно меняются при малейшем изменении данных.

**Как бороться:**

- Регуляризация (Ridge/Lasso/Elastic Net) — основной инструмент.
- Уменьшение числа признаков (feature selection).
- Увеличение объёма обучающих данных.
- Кросс-валидация для честной оценки и подбора `alpha`.

## 9. Плюсы

- Высокая интерпретируемость: каждый коэффициент напрямую показывает влияние признака.
- Очень быстрое обучение и предсказание, даже на больших данных.
- Не требует настройки множества гиперпараметров.
- Математически хорошо изучена, есть готовые доверительные интервалы для коэффициентов, статистические тесты значимости.
- Хорошая отправная точка (baseline) почти для любой regression-задачи.

## 10. Минусы

- Предполагает **линейную** зависимость между признаками и целевой переменной — не улавливает сложные нелинейные закономерности.
- Чувствительна к выбросам (из-за квадратичной функции потерь).
- Чувствительна к мультиколлинеарности признаков.
- Требует ручной инженерии признаков для нелинейных зависимостей (полиномиальные признаки, логарифмирование и т.д.).
- Предполагает независимость и гомоскедастичность остатков (для корректности статистических выводов, хотя для чистого предсказания это менее критично).

## 11. Когда использовать

- Зависимость между признаками и целью действительно близка к линейной (или может быть приближена ей после преобразований).
- Нужна высокая интерпретируемость (например, регуляторные требования в банковской сфере).
- Нужен быстрый и понятный baseline перед тем, как пробовать более сложные модели.
- Небольшой или средний датасет, немного признаков.

## 12. Когда НЕ использовать

- Явно нелинейная, сложная зависимость (в этом случае лучше Random Forest, Gradient Boosting и т.д. — Часть 4).
- Данные с очень большим количеством выбросов без предварительной обработки.
- Задача классификации (для неё — Logistic Regression, Часть 3, несмотря на схожее название).

## 13. Бизнес-примеры

**House price prediction:** Business Problem — оценить справедливую рыночную стоимость квартиры → Data — база проданных объектов → Features — площадь, район, этаж, год постройки → Model — Linear/Ridge Regression → Metric — RMSE в рублях → Business Impact — автоматическая оценка объектов для риэлторского сервиса, ускорение сделок.

**Revenue forecasting:** предсказание выручки на основе маркетингового бюджета, сезонности и числа активных клиентов — помогает планировать бюджет отдела продаж.

## 14. Как оценивать

Основные метрики — MAE, MSE, RMSE, R² (подробный разбор каждой — в Части 6 "Model Evaluation"). Кратко: R² показывает, какую долю дисперсии целевой переменной объясняет модель (1.0 — идеально, 0 — не лучше константного предсказания среднего).

## 15. Сравнение с альтернативами

|Модель|Линейность|Интерпретируемость|Скорость|Когда лучше|
|---|---|---|---|---|
|Linear Regression|Только линейные зависимости|Максимальная|Очень высокая|Простые, линейные задачи, нужна интерпретируемость|
|Ridge/Lasso|Линейные|Высокая|Высокая|Много признаков, мультиколлинеарность|
|Random Forest (Часть 4)|Нелинейные|Средняя|Средняя|Сложные нелинейные зависимости, не нужна строгая интерпретируемость коэффициентов|
|Gradient Boosting (Часть 4)|Нелинейные|Низкая (без SHAP)|Ниже (но выше качество)|Максимальное качество на табличных данных|

## 16. Что нужно запомнить

> - Linear Regression ищет линейную зависимость, минимизируя MSE — сумму квадратов остатков.
> - Обучение возможно двумя способами: Gradient Descent (итеративно, универсально) и Normal Equation (аналитически, только для линейной регрессии).
> - Ridge (L2) сжимает коэффициенты, но не обнуляет их; Lasso (L1) может обнулять коэффициенты полностью (feature selection); Elastic Net — комбинация обоих.
> - Модель чувствительна к выбросам и мультиколлинеарности, перед регуляризацией признаки нужно масштабировать.
> - Это отличный интерпретируемый baseline, но не подходит для сложных нелинейных зависимостей.
