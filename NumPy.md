NumPy (Numerical Python) — это базовая библиотека [[Python]] с открытым исходным кодом для научных вычислений, анализа данных и машинного обучения. Она обеспечивает высокопроизводительную работу с многомерными массивами и матрицами, значительно превосходя стандартные списки [[Python]] по скорости за счет использования C-расширений.

```python
import NumPy as np
```

Основным объектом NumPy является одномерный массив, существует несколько способов создать его:
```python
A = np.array([1,2,3]) #функция, создающая объект типа ndarray 
A = np.array([1.9,2.0,4.8,5.8],dtype = np.complex) #можно переопределить тип данных в момент создания
np.zeros((3, 5)) # массив, состоящий из нулей размером 3х5
np.ones((3, 5, 2)) # массив, состоящий из единиц
np.eye(5) # создание единичной матрицы размером 5х5
np.empty((4,5)) # создает массив без заполнения, значения элементов зависят от того, что хранится в памяти
```
Для создания последовательности также есть функция:
```python
np.arrange(0,5,1) # функция вернет массив, состоящий из элементов [0,1,2,3,4]
```
Если массив слишком большой, чтобы его печатать, NumPy автоматически скрывает центральную часть массива и выводит только его уголки.
Если действительно нужно увидеть весь массив, используйте функцию numpy.set_printoptions:
```python
np.set_printoptions(threshold=np.nan)
```
И вообще, с помощью этой функции можно настроить печать массивов "под себя". Функция  принимает несколько аргументов:
_precision_ : количество отображаемых цифр после запятой (по умолчанию 8).
_threshold_ : количество элементов в массиве, вызывающее обрезание элементов (по умолчанию 1000).
_edgeitems_ : количество элементов в начале и в конце каждой размерности массива (по умолчанию 3).
_linewidth_ : количество символов в строке, после которых осуществляется перенос (по умолчанию 75).
_suppress_ : если True, не печатает маленькие значения в scientific notation (по умолчанию False).
_nanstr_ : строковое представление NaN (по умолчанию 'nan').
_infstr_ : строковое представление inf (по умолчанию 'inf').
_formatter_ : позволяет более тонко управлять печатью массивов.

## Базовые операции
Математические операции над массивами выполняются поэлементно. Создается новый массив, который заполняется результатами действия оператора. <u>Массивы должны быть одинаковых размеров</u>.
```python
a = np.array(1,2,3,4)
b = np.array(20,40,50)
a+b
a-b
a**b
```
Также можно производить математические операции между массивом и числом. В этом случае к каждому элементу прибавляется это число.
```python
a*3
b+1
```
Многие унарные операции, такие как, например, вычисление суммы всех элементов массива, представлены также и в виде методов класса ndarray.
```python
np.sum(a)
a.min()
```
По умолчанию, эти операции применяются к массиву, как если бы он был списком чисел, независимо от его формы. Однако, указав параметр axis, можно применить операцию для указанной оси массива.
```python
a.min(axis=0)
```
## Индексы, срезы, итерации
Одномерные массивы осуществляют операции индексирования, срезов и итераций очень схожим образом с обычными списками и другими последовательностями Python.
```python
a = np.array(1,2,3,4,5)

a[1:3] # output 2,3
a[1:3] = 7 # output 1,7,7,4,5
a[::-1] # output 5,4,7,7,1
	
```
## Манипуляции с формой
У массивов есть форма(shape).
```python
a = np.ones(2,2,2) 
a.shape # output 2,2,2

a.ravel() # делает массив плоским
a.shape() # output 6
a.shape() = (2,3) # изменит размер массива на 2х3
a.transpose() # транспонирование
a.reshape(3,2) # изменеие размера
```
## Объединение массивов
Несколько массивов могут быть объединены вместе вдоль разных осей с помощью функций hstack и vstack.
hstack() объединяет массивы по первым осям, vstack() — по последним:
```python
a = np.array([[1,2],[2,3]])
b = np.array([[4,5],[6,7]])
np.vstack(a,b)
np.hstack(a,b)
```
Также есть np.column_stack() и np.row_stack().
## Разбиение массива
Используя hsplit() вы можете разбить массив вдоль горизонтальной оси, указав либо число возвращаемых массивов одинаковой формы, либо номера столбцов, после которых массив разрезается "ножницами":
```python
np.hsplit(a,3) # разбить массив а на 3 части
np.hsplit(a,(3,4)) # разрезать массив а после 3 и 4 столбца
```
## Копии и представления
При работе с массивами, их данные иногда необходимо копировать в другой массив, а иногда нет. Это часто является источником путаницы. Возможно 3 случая:
1) Никаких копий.
```python
a = np.arrange(12)
a=b
a is b
```
2) Представление или поверхностная копия.
```python
c = a.view #метод создает новый объект, являющийся представлением тех же данных
c not a
```
3) Глубокая копия.
```python
d = a.copy() # создает новый объект массива с новыми данными
d not a
```
## NumPy Random
Библиотека NumPy содержит модуль np.random для создания случайных чисел.
```python
a = np.random.sample(3) # массив из 3 случайных чисел
```
Можно также перемешать массив при помощи функции shuffle.
```python
a = np.arrange(10)
np.random.shuffle(a)
```
## Инициализация генератора случайных чисел
seed(число) - инициализация генератора.
```python
np.random.seed(1000)
np.random.random(10) # массив из 10 псевдослучайных чисел
```

## Разложения
```python

linalg.cholesky(a) # разложение Холецкого.

linalg.qr(a[, mode]) #QR разложение.

linalg.svd(a[, full_matrices, compute_uv]) #сингулярное разложение.
```

## Некоторые характеристики матриц
```python

linalg.eig(a) - собственные значения и собственные векторы.

linalg.norm(x[, ord, axis]) - норма вектора или оператора.

linalg.cond(x[, p]) - число обусловленности.

linalg.det(a) - определитель.

linalg.slogdet(a) - знак и логарифм определителя (для избежания переполнения, если сам определитель очень маленький).
```

## Системы уравнений
```python

linalg.solve(a, b) # решает систему линейных уравнений Ax = b.

linalg.tensorsolve(a, b[, axes]) # решает тензорную систему линейных уравнений Ax = b.

linalg.lstsq(a, b[, rcond]) # метод наименьших квадратов.

linalg.inv(a) # обратная матрица.
```
