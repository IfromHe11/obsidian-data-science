Инструмент для создания ноутбуков с использованием [[Python]], [[SQL]] и тд.
https://github.com/marimo-team/marimo DOcs
Для работы, необходима установка:
```Bash
pip install marimo
```
Для запуска:
Настраиваем виртуальное окружение venv или же UV и уже в нем выполняем запуск
```Bash
marimo edit
```
В этом же окружении устанавливаются все библиотеки.
