Pandas — это популярная библиотека [[Python]] для обработки, анализа и очистки структурированных данных (таблиц, временных рядов). Основные структуры данных — Series (одномерные) и DataFrame (двумерные, как Excel). Она обеспечивает быструю фильтрацию, группировку, объединение и чтение/запись данных (CSV, Excel, SQL).
Для работы с [[Pandas]] часто требуется библиотека [[NumPy]].
```python
import pandas as pd
import NumPy as np
```

## Применение функции к данным
Метод `apply()` в pandas — это гибкий инструмент для применения пользовательской или встроенной функции к данным: к каждому элементу столбца (Series) или целиком к строкам/столбцам DataFrame.
```python
import pandas as pd
df = pd.DataFrame({'A': [1, 2, 3], 'B': [4, 5, 6]})
# Применение lambda-функции к столбцу
df['A_new'] = df['A'].apply(lambda x: x * 10)
# Применение функции к строке (сумма столбцов A и B)
df['Total'] = df.apply(lambda row: row['A'] + row['B'], axis=1)
print(df)
#    A  B  A_new  Total
# 0  1  4     10      5
# 1  2  5     20      7
# 2  3  6     30      9
```
